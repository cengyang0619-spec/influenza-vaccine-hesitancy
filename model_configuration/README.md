# Model configuration

Document the exact model configurations used at each stage of the study.

For each model/stage, report where applicable:

- model name and dated snapshot/version identifier;
- hosted versus self-hosted inference;
- inference date(s);
- fine-tuned model identifier and whether weights are exportable/servable;
- temperature;
- top_p;
- seed;
- max_tokens;
- whether thinking/reasoning mode was enabled;
- response-format constraints (for example, JSON output);
- timeout and retry handling;
- handling of truncation, malformed output, empty responses, and failed requests;
- whether any forced-assignment procedure was used.

Do not include API keys or other credentials.
