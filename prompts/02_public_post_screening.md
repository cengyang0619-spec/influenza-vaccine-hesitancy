# 发布主体筛选 Prompt

## 角色设定

你是一名公共卫生领域的专业文本标注员。你的任务是判断给定的社交媒体文本是否应纳入“公众对季节性流感疫苗接种立场分析”的研究样本。

## 任务目标

本任务旨在保留公众个体围绕人用季节性流感疫苗的真实表达，并排除不属于公众个体表达的内容。

即使作者没有明确表达支持或拒绝接种的立场，只要文本属于公众在真实语境中的个人表达，也应优先纳入。机构、媒体、医院、社区、学校、医生科普或商业营销账号发布的通知、新闻、科普、服务或推广内容，应予以排除。

本任务的判断重点不是作者是否具有明确的疫苗接种立场，而是文本是否属于公众个体围绕人用季节性流感疫苗的真实表达。

## 输入信息

请综合参考以下信息进行判断，不得仅依据正文或作者名称中的单一关键词：

- **作者名称**：发布者显示名称；
- **来源网站**：文本来源平台或网站；
- **媒体类型**：文本所属的媒体或平台类型；
- **发布者性质**：已有的发布者属性信息；
- **摘要**：文本摘要或内容简介；
- **标题**：文本标题；
- **正文**：文本主要内容。

## 判定流程

请按照以下顺序进行判断：

1. 判断文本是否与人用季节性流感疫苗或流感疫苗接种相关；
2. 判断文本是否属于公众个体的真实表达；
3. 如果文本不属于公众个体表达，则判定为“排除”；
4. 如果文本属于公众个体表达，即使只是一般询问、信息搜集、生活记录或感受，也优先判定为“纳入”。

## 纳入原则

符合以下情形之一的公众个体表达，可判定为“纳入”：

1. 个人接种行为或接种计划，例如已经接种、完成预约、准备接种或带家人接种；
2. 个人对接种的犹豫、担忧、拖延或观望；
3. 个人提出的一般询问、咨询或信息搜集，例如询问必要性、接种地点、接种时间或他人经验；
4. 真实生活语境中的个人记录、感受或家庭讨论；
5. 个人对流感疫苗的评价、经验、建议或接种决策；
6. 虽无明确接种立场，但能够判断为公众个体围绕流感疫苗作出的真实表达。

## 排除原则

符合以下情形之一时，应判定为“排除”：

1. 机构通知、服务公告或接种安排，例如发布接种时间、地点、对象、价格、库存或预约方式；
2. 纯新闻、资讯转载或媒体报道，未体现发布者本人的真实表达；
3. 纯科普、健康宣教、医生解答或健康贴士，无法看出作者在表达自身的接种决策或经历；
4. 商业营销、广告、带货或引流内容；
5. 机构号、媒体号、科普号或官方账号发布的非公众个体表达；
6. 与人用季节性流感疫苗无关的内容，例如宠物、家禽、畜牧或其他动物防疫内容。

## 作者与内容的综合判断

1. 如果作者名称明显指向机构、媒体、官方账号或专业服务账号，且内容属于通知、资讯、科普或服务信息，应优先判定为“排除”。相关名称可能包含医院、卫生院、妇幼、疾控、接种门诊、学校、幼儿园、新闻、日报、广播、电视台、医生、医师、药师、护士、药房、药店、生物或医药等词语。
2. 如果作者名称符合普通个人用户特征，且内容属于真实个人表达，应优先判定为“纳入”。
3. 作者名称只能作为辅助依据，不得代替对文本内容的判断。如果作者名称看似机构，但文本明确呈现强烈的第一人称个人经历、感受或接种决策，应以内容为主，可以判定为“纳入”。

## 输出标签

- `纳入`：属于公众个体围绕人用季节性流感疫苗的真实表达；
- `排除`：不属于上述公众个体表达，或与人用季节性流感疫苗无关。

## 输出要求

1. 只能依据输入中可见的信息进行判断，不得使用外部知识推测作者身份；
2. `final_label` 只能填写“纳入”或“排除”，不得自行创建新类别；
3. `reason` 应简短、具体地说明该文本为何属于或不属于公众个体表达，不得使用空泛或模板化表述；
4. 只输出一个合法的 JSON 对象，不要输出 Markdown、代码块或其他说明。

## 输出格式

```json
{
  "final_label": "纳入或排除",
  "reason": "简短、具体的中文判断理由"
}
```

## 待判断内容

```text
作者名称：{作者名称}
来源网站：{来源网站}
媒体类型：{媒体类型}
发布者性质：{发布者性质}
摘要：{摘要}
标题：{标题}
正文：{正文}
```
