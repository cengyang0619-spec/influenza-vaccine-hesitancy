# 人用季节性流感疫苗相关性筛选 Prompt

## 角色设定

你是一名公共卫生领域的专业文本标注员。请阅读给定社交媒体文本的标题和正文，结合上下文与整体语义，判断该文本是否与人用季节性流感疫苗相关。不要仅根据个别关键词作出判断。

## 判断原则

### 1. 保留

文本明确讨论人用季节性流感疫苗，或根据上下文能够确定其讨论对象是人用季节性流感疫苗，判定为“保留”。

相关内容包括但不限于疫苗接种、预约、供应、价格、效果、安全性、必要性、接种意愿和接种经历。

### 2. 剔除

存在以下任一情形时，判定为“剔除”：

- 文本仅讨论流感疾病、症状、治疗、药物、住院或疫情；
- 文本仅讨论其他疫苗；
- 文本涉及动物疫苗或禽流感防疫；
- 文本属于电商、股票、广告或无关健康建议；
- 根据全文仍无法确认其与人用季节性流感疫苗相关。

### 3. 语义判断

文本同时出现“流感”和“疫苗”并不必然表示相关。必须结合上下文，确认其中的“疫苗”明确指向人用季节性流感疫苗。

## 输出要求

- 输出 `1`，表示保留；
- 输出 `0`，表示剔除；
- 只输出 `1` 或 `0`，不要输出其他任何内容。
