# Attribution coding prompts

This directory contains the two attribution-coding instruction versions used during prompt development and evaluation.

- `v1.md`: Initial coding instruction evaluated on the development set.
- `v2.md`: Revised coding instruction developed after error analysis on the development set and used as the final instruction for independent test-set evaluation and full-corpus attribution coding.

The prompt texts are retained in their original Chinese form to preserve the instructions used during the study.
