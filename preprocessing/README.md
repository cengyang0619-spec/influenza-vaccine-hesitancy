# Preprocessing

This directory contains the main rule-based preprocessing scripts used to prepare the social-media records for subsequent LLM-based screening and analysis.

The scripts cover text standardization, exact deduplication, structural-noise filtering, rule-based relevance screening, and conservative rule-based screening of obvious non-public posts.

## Workflow

The preprocessing workflow is organized as follows:

1. `01_pre_dedup.py`
   - Standardizes publication time.
   - Cleans title and body text.
   - Merges title and body for deduplication.
   - Removes links and selected platform-specific display tokens from the deduplication text.
   - Generates a normalized text field for subsequent deduplication.

2. `02_dedup.py`
   - Performs exact URL-based deduplication when a URL is available.
   - Performs exact deduplication based on the title-body combination.
   - Keeps the first occurrence of duplicate records.

3. `03_structural_filtering.py`
   - Removes records with empty text.
   - Removes link-only records.
   - Removes garbled or symbol-dominated text.
   - Removes very short meaningless text.
   - Removes template-placeholder content.

4. `04_rule_based_relevance.py`
   - Applies rule-based screening for relevance to human seasonal influenza vaccination.
   - Uses explicit influenza-vaccine terms, vaccination-related context, and predefined exclusion terms.
   - Assigns records to `keep_rule`, `borderline_rule`, or `drop_rule`.
   - Semantic relevance screening requiring LLM judgment is performed using `../prompts/01_relevance_screening.md`.

5. `05_rule_based_public_post_screening.py`
   - Conservatively removes records with strong and concordant evidence of being non-public content.
   - Rule-based exclusions include institutional notices, school notices, news or media content, professional health education, and commercial promotion.
   - Records not excluded by these rules are assigned `llm_review` for subsequent semantic screening.
   - The corresponding LLM prompt is available at `../prompts/02_public_post_screening.md`.

## Overall sequence

```text
Raw records
    ↓
Basic text and time standardization
    ↓
Exact deduplication
    ↓
Structural-noise filtering
    ↓
Rule-based relevance screening
    ↓
LLM-based relevance screening
    ↓
Rule-based public-post screening
    ↓
LLM-based public-post screening
    ↓
Final analytic records
```

## Requirements

The scripts were written in Python and primarily use:

- `pandas`
- `tqdm`

The exact package versions may depend on the local execution environment.

## Usage

Each script accepts input and output locations at runtime rather than relying on machine-specific absolute paths.

Example:

```bash
python 01_pre_dedup.py --input raw_records.csv --output preprocessed_records.csv
```

Subsequent scripts can then be run on the output generated by the preceding stage.

See the command-line help for each script for the available arguments:

```bash
python <script_name>.py --help
```

## Notes

The preprocessing code is provided to document the main deterministic data-cleaning and rule-based screening procedures used in the study.

LLM prompts are stored separately in the `prompts/` directory.

Individual-level social-media records are not included in this repository.
