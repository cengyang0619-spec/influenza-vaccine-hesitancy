# Documentation

Use this directory for documentation that helps readers understand and reproduce the computational workflow without access to the restricted raw social-media corpus.

Suggested files include:

- `workflow.md`: end-to-end computational workflow;
- `data_dictionary.md`: field definitions for shareable intermediate or aggregated data;
- `reproducibility_notes.md`: software environment, package versions, and execution order;
- `data_access_notes.md`: boundaries on redistribution of raw social-media records.
